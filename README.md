# Hwa Chong Institution (Junior College) Orientation 2022 Scoreboard
## Features
- Separate desktop and mobile layouts
- Responsive presentation across different screen sizes
- Orientation instructions and links to additional information
- Smooth scrolling on mobile

## About
The leaderboard encouraged Orientation Groups to participate in OGIG challenges and other orientation activities. Scores were updated throughout the event, with the website now preserving the final results.
